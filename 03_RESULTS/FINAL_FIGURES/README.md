# Final figures

Empty until the paper's figures are chosen.

When a figure is chosen, add a relative link here pointing at the canonical file, not
a copy:

```bash
ln -s ../../Age_trajectory/results/figures/<file>.png 03_RESULTS/FINAL_FIGURES/Fig2A_<name>.png
```

Name each link after its place in the paper (`Fig1`, `Fig2A`, …), so this folder reads
as the paper's figure list.
