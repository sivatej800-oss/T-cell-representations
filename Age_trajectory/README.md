# Generated pipeline workspace

`Age_trajectory/` is the default workspace for the pipeline (Stages 01–15 under
`02_CODE/`). It contains inputs downloaded by the pipeline, intermediate objects, audit
records, expensive checkpoints, and final outputs. The directory is ignored by Git
except for three things that are tracked on purpose: this README,
`results/README.md`, and the PNGs under `results/figures/`. The figures are tracked so
that the links in `03_RESULTS/` resolve on GitHub; everything else those links point to
is only present after the pipeline has been run. The rules are in the repository
`.gitignore`.

Do not run files from this directory. Run the numbered commands under `02_CODE/` from
the repository root. To use another workspace, pass the same `--workspace PATH` to
every stage.

## Directory ownership

```text
Age_trajectory/
├── data/
│   ├── raw/                         # Stage 01 GEO downloads
│   ├── interim/                     # Stage 01 sparse matrices/ordered identifiers
│   ├── metadata/                    # Stage 01 sample- and cell-level metadata
│   ├── processed/                   # Stage 01 AnnData objects
│   └── scgpt/                       # Frozen scGPT embedding bundle (input to Stage 04)
├── logs/                            # Checksums and construction/run summaries
├── tables/                          # Sparse-conversion and QC audit tables
├── archive/legacy_notebook_outputs/ # Generated by superseded notebook workflows
└── results/
    ├── 03_seurat_reproduction/      # Stages 02-03: QC audit, seurat_input/, sct_samples/,
    │                                #   *.rds checkpoints, UMAP/cluster table
    ├── 04_scgpt_embedding/          # Stages 04-05: r_input/, scGPT clustering, gene-coverage audit
    ├── 06_harmony_benchmark/        # Stages 06 and 10: Harmony benchmark, PCA-512 arm
    ├── 07_silhouette/               # Stage 07
    ├── 08_wcss_sweep/               # Stage 08
    ├── 11_silhouette_matched/       # Stage 11
    ├── 12_frozen_labels/            # Stage 12
    ├── 13_marker_discovery/         # Stage 13
    ├── 14_marker_evidence/          # Stage 14
    ├── 15_annotation/               # Stage 15
    └── figures/                     # PNGs from Stages 03-15 (tracked in git)
```

Stage 09 writes only to `results/figures/`. The `results/NN_*` names are read by the
scripts and must not be renamed.

## Safe cleanup rules

- Never remove checkpoints merely because they are large if integration might need to
  resume.
- A file ending in `.tmp` is an incomplete atomic write. Remove it only after verifying
  that the corresponding completed artifact exists.
- `seurat_input/` (under `results/03_seurat_reproduction/`) can be regenerated by Stage 02, but Stage 03 needs it when neither an
  integrated nor a post-PCA checkpoint is available.
- Logs, checksum JSON, manifests, mapping tables, and validation CSVs are small and
  should remain with the analysis for provenance.
- `archive/legacy_notebook_outputs/` is ignored, generated provenance. Nothing in the
  maintained scripts reads from it.
- Use a new `--workspace` instead of `--force` when you want an independent clean run.
