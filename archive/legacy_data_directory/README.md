# Archived data-directory note

This was the README for an unused root-level `data/` placeholder. It is archived
because the maintained pipeline stores all generated data in `Age_trajectory/` by
default, or in the directory selected with `--workspace`.

Do not put current pipeline inputs or outputs here. Follow the top-level README and
retain the original GEO accession and checksums in the active workspace logs.

Do not place credentials, controlled-access data, directly identifying data, or unapproved participant-level exports in this directory.
